# Expression bank — 24 October 2026 (PKT)

22 replacement portraits generated using the built-in image tool and the three user-approved facial references. Original generation prompts, SHA-256 hashes and dimensions are recorded in [expression-bank.json](../assets/approved_identity/expression-bank.json).

These assets received assistant visual review, not individual user approval or a biometric identity test. No claim of perfect identity, exact Dell model geometry, exact physical room reconstruction or real iPhone capture is made. The requested look is casual photographic office imagery. Some expressions are intentionally subtle. Minor edge/prop and facial-detail differences remain possible.

The user authorized replacement of the historical portraits and continuation after approving the front/left/right references. This replaces only the 22 named PNG files; old versions remain recoverable in Git history. Rejected earlier generation attempts are not included.
